# Changelog

## 26.1.0 - 2026-09-12

- Migrated License Hub requests and online help to HTTPS-only URLs.
- Added cross-platform Device ID generation while preserving existing Windows
  MachineGuid-derived IDs.
- Added QGIS network-manager support for system proxy and TLS settings.
- Added CRS-aware square-metre measurements and cross-CRS Pair Overlap.
- Added a spatial index to reduce unnecessary geometry comparisons.
- Corrected Self Overlap summaries so both participating features are updated.
- Made generated field names collision-safe for the Shapefile format.
- Counted trial usage only after a successful analysis.
- Added GPL-3.0-or-later licensing and publication documentation.
- Added small synthetic GeoJSON files for reproducible functional testing.
- Added a live 0-100 percent analysis progress bar with stage messages.

## 0.26.01

- Updated the main action label and plugin description.
- Added project-layer and file-based polygon inputs.
- Added the License Hub activation interface.
