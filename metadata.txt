about=Overlap Report helps identify self-overlaps and intersections between polygon layers quickly and accurately. It provides Self Overlap and Pair Overlap analyses in one focused interface, creates a copy of the primary polygon layer with overlap summaries, and creates a separate polygon layer containing every detected intersection. Areas are reported in square metres, including when input layers use geographic or different coordinate reference systems. The plugin supports QGIS 3.22 through 3.99 within the QGIS 3.x series; QGIS 4 compatibility is not claimed.
version=26.1.0
author=Dwi Purwanto (Ruang Spasial)
email=ruangspasial@gmail.com
changelog=26.1.0
    - Detects self-overlaps between polygon features within a single layer.
    - Analyses intersections between primary and secondary polygon layers.
    - Supports polygon layers with matching or different coordinate reference systems.
    - Creates a primary report containing overlap summaries, areas in square metres, and percentages.
    - Creates a separate detail layer containing every overlap geometry and its source feature identifiers.
    - Allows selected primary-layer attributes to be included in the detailed result.
    - Uses spatial indexing for efficient analysis and displays live progress from 0 to 100 percent.
    - Supports polygon layers loaded in QGIS or selected directly from a folder.
